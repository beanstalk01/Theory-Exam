# RoadReady AD — Light Vehicle Automatic

Abu Dhabi light-vehicle automatic theory exam simulator based on the uploaded Emirates Driving Company Light Vehicle Handbook.

- 140 original handbook-based practice questions
- 8 prepared 45-question mock exams
- 30-minute countdown and 36/45 (80%) practice target
- Visual road-sign questions
- Situational judgement and automatic-car controls
- Motorcycle content excluded
- Topic study, mistake review, score tracking and offline PWA support

The exact current exam format is not clearly published on official public EDC/TAMM pages. Confirm with EDC before the appointment. Questions are original practice items, not leaked live exam questions.
